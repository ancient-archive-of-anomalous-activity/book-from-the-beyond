File No. #477-014-2791

Code And ID#: OKZ-2791

Location: Site #477, Formerly Known As Site #119

Protocol: All files are to be delted, if possible, and otherwise censored as heavily as possible. Destruction of the object is to be attempted at least twice a week.

Description: Object #2791 is a computer formerly used for general record keeping and documentation purposes by the staff of the now decomissioned site #119. After the event that compromised site #119, the object became compromised as well, and has since been publicly publishing highly classified instititue files and documents to the public. It is impossible to destroy it by any means. Most of the files it uploads are possible to delete, but there are several that are imposible to dispose of, though, some can be censored and edited. The existence of the instititue, and the sort of phenomena that it studies have, as of yet, not become widely known to the public, thought it is uncertain if this is due to an anomaloys effect that the documents published might have on the reader, or if they have merely remained undiscovered for now. While the object itself is completely harmless, finding a way to destroy it is vital for the continued integrity of the institute's mission, and this thus of extremely high priority.
