Anomalous Phenomenon File Template

File No. #Site#-YYY-ID#

Code And ID Number: ThreeLetters-#ID
Letter #1 - Type Of Phenomenon: E, O, L (E - Entity, O - Object, L - Location)
Letter #2 - Containment Class: K, R, C (K - Kill, R - Ritual or Released, C - Contain or Cage)
Letter #3 - Threat Level: X, V, Z (X Level 10+, V Level 5-10, Z Level 0-5)
ID# is unique, sequential, and never changes. YYY = Last Three Digits Of The Year Of Recording

Location: Site#

Protocol: Protocol description, may be split into caputre, containment and destruction protocol if necessary.

Description: Description

Report And Log File Template

#TwoLetters-Site#-YYY-MM-DD-ID#

Letter #1 - Type Of Event Or Action: I, E, M (I - Incident, E - Experiment, M - Mission)
Letter #2 - Type Of Document Or Evidence: R, L (R - Report, L - Log)
ID# is sequential, but unique only to the site and date, and separate from the list of ID#s of anomalies recorded.
